# Play Store Scanner

A pretend grocery-store checkout for kids. Hold a toy up to the iPad camera and it "scans" it with a beep, gives it a silly name and price, and adds it to the receipt. Tap Pay for cash or card, then confetti.

Open `index.html` in Safari (it needs https for the camera, e.g. GitHub Pages). Tap Share → Add to Home Screen to run it full screen.
